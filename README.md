# 프로젝트 이름 : BOOKTOPIA

![logo](booktopia/www/src/main/resources/static/image/logo.png)

### ▶ 개발목적
- 사용자의 도서 취향과 스타일을 분석
- 취향에 맞는 도서를 사용자에게 배송
- 도서에 대한 객관적인 의견을 토론하고 투표하는 커뮤니티

### ▶ 프로젝트 일정
- 24.05.20~24.06.26(6주)

### ▶ 개발 환경
- OS : Window 10
- IDE: IntelliJ 24.1.2
- JAVA: Oracle OpenJDK 17.0.10
- DBMS : MySQL 8.0
- Communication : Canva, Slack, GitHub

### ▶ 담당 파트
- **공통 구성**: ERD 설계 및 전체적인 화면 디자인 구성 및 기능
- **가명선**: 결제API, 취향검사, 챗봇, 관리자페이지 기능구성 및 CSS
- **김정온**: 결제API, 글쓰기API(TOAST UI), 커뮤니티 게시판 CRUD, 쿠폰사용 기능, 결제내역/쿠폰/주문서작성/커뮤니티 전체 페이지 CSS
- **오하은**: 소셜로그인API, 지도API, 일반 회원가입/로그인 기능, 구독정보/메인/취향검사/검사결과 페이지 CSS
- **윤지명**: 소셜로그인API, 일반 로그인 기능, 회원 탈퇴, 마이페이지 로직 구현, 1대1 문의 기능 및 CSS
  - 회원은 일반로그인과 소셜로그인을 나누어서 기능에 따라 활성화/비활성화를 설정하였습니다.
  - 회원탈퇴를 진행할시 일반 로그인과 소셜로그인에 대한 경로를 다르게 설정하여 원활히 회원탈퇴가 진행되도록 하였습니다.
  - 소셜 회원은 로그인시 배송에 필요한 주소를 받기 위해 최초 로그인시 자신의 주소를 받을수 있도록 마이페이지로 연결되도록 설정하였습니다.
  - 쿠폰은 js를 사용하여 받은 날짜대로 정렬하고, 사용여부에 따라 사용/미사용으로 정렬되도록 설정하였습니다.
  - 1:1 문의는 js를 사용하여 관리자가 해당 문의에 대한 코멘트를 보내어 문의사항을 채택 하였으면 마이페이지 답변/미답변으로 설정하였습니다.
